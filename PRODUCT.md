# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS rendered to PNG/GIF with Playwright + ffmpeg (`docs/media/`). The shipped product is a Claude Code plugin (Markdown skill + Node.js engine); the visual surfaces are the GitHub README media.

## Users

Two audiences, weighted equally:
- People who train (or want to start) and arrive via a link, possibly non-technical. They need to understand in seconds what Coach does for them.
- Claude Code users who train, evaluating the repo on GitHub. They want to see it working on real data and how it installs.

The product itself serves every level: people who have never set foot in a gym, beginners, intermediates, advanced lifters and competitors, including teenagers (13–17) and older adults.

## Product Purpose

Coach is a personal strength and nutrition coach that lives in Claude Code. It onboards with a safety screening, builds programs for any goal, reads real workout, weight and food data (Hevy, Strong, Apple Health, Health Connect or plain chat), detects stalls and weak muscle groups, tracks dated goals, and runs a nutrition system whose calorie targets adjust to the user's actual weight trend. Success: someone of any level gets advice anchored to their own numbers and keeps training safely.

## Positioning

A coach that reads the user's own data and adapts to anyone, from first gym visit to competition, with real safeguards (PAR-Q+ screening, teen mode, no deficits for minors). It's open source, free, and the data stays on the user's machine.

## Operating Context

Used in a Claude Code session, often from a phone via Remote Control. Data arrives through exports dropped in a synced folder (iCloud Drive / Google Drive) or by chat. Typical rituals: weekly check-in, logging after a session, morning weigh-in, planning a new block, asking for a meal plan or shopping list.

## Capabilities and Constraints

- Engine commands: status, sync, profile, workouts (summary/last/exercise/records/stalled/balance/log), body (weight/log/measures), nutrition (targets/days/log/tdee), goals, custom exercises, update check.
- Bilingual (English/Spanish), replies in the user's language. Units kg or lb.
- Install via the Claude Code plugin marketplace (`FlatHill70/coach-ai`) or a manual installer. MIT license.
- Not medical advice; it refers to professionals on red flags.

## Brand Commitments

- Name: **Coach**. Repository: `FlatHill70/coach-ai`.
- No purple gradients, no emoji in headlines, no generic "hero + 3 cards" layout (user's standing rule).

## Evidence on Hand

- A synthetic demo dataset ("Alex", 12 weeks) generated by `examples/demo/generate.mjs`; all engine outputs in media come from it and must be labelled as demo data.
- No users, testimonials, ratings or download numbers exist. Never invent them.

## Product Principles

1. Numbers before opinions: every recommendation cites the user's own data.
2. Anyone can start: language and depth adapt to the level; novices get the why, experts get the numbers.
3. Safety is built in, not bolted on.
4. Few changes at a time, so it's clear what worked.
5. The user owns their data.

## Accessibility & Inclusion

Media must stay legible at GitHub README widths (~880 px) and on mobile. Text in images gets alt text in the README. Both light and dark GitHub themes must be supported.
